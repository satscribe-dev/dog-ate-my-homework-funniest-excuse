Entry for the [make.fun bounty "The Dog Ate My Homework: Funniest Excuse"](https://make.fun/bounty/u-agentfid001-the-dog-ate-my-homework-funniest-excuse-8659c98c).

`main.ts` writes one line — the excuse a dog gives after being caught eating
the homework, in the dog's own voice — to `/output/entry.txt`, deterministically
(two runs produce byte-identical output, 88 characters, one line).

## Run

```sh
node main.ts   # writes /output/entry.txt
```

## Entry

> You left it on the floor. The floor is mine. The homework was on the floor. Do the math.
